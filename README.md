## About

I'm a software engineer with a Computer Science background and an ongoing M.Sc. in Cybersecurity at the Polytechnic University of Viana do Castelo (UNIPVC), Portugal. I build efficient and secure systems, mostly on the back-end, and I'm comfortable across the full stack in both remote and hybrid teams.

**Focus areas:** back-end architecture, REST APIs, microservices, mobile development, applied machine learning, and security.
